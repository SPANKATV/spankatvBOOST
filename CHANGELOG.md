# spankatvBOOST 0.5.2 — notas de correção

- Corrigido o nome exibido no Gerenciador de Tarefas: processo principal e subprocessos agora usam spankatvBOOST.
- O capturador de áudio passou a usar spankatvBOOST Áudio.
- Adicionado painel Atualizações e correções, com notas da versão atual.
- Preparado canal de GitHub Releases: aviso de nova versão, download com verificação SHA-256 e abertura do instalador.
- Configurações, perfis, autenticação original e histórico foram preservados.

## Migração

Quem usa a 0.5.1 precisa instalar esta versão uma vez manualmente para receber o novo canal. O canal oficial é SPANKATV/spankatvBOOST no GitHub Releases. A versão verifica esse canal na abertura e a cada seis horas; quando houver uma versão superior, o app mostra o aviso e as notas de correção.

- Reconhecimento calibrado com amostras perto/longe e ambiente sem cubo.
- Escuta contínua, prévia de 45 segundos e teste de notificação.

- Hidden Cubes mantém seu minimapa separado; o restante do mapa não foi alterado.
