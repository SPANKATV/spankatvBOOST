# spankatvBOOST 0.5.3 — identidade dos overlays

- O botão flutuante de controles agora usa a logo SPANKATV no lugar das três barras.
- A logo também aparece no cabeçalho dos controles e no seletor do botão do overlay.
- Barras de título, bordas, controles e barra de rolagem dos overlays usam azul-marinho e ciano da interface SPANKATV.
- O atalho Alt+E, os cliques, a posição, o tamanho e a transparência dos overlays foram preservados.
- A interface local Fusion também recebeu a logo no botão flutuante.
- Revisados os nomes visíveis do aplicativo para spankatvBOOST, preservando os créditos e identificadores técnicos dos serviços originais.
- Corrigida a seção Versão das configurações, que ainda mostrava a versão do a2finder e instruções de atualização incompatíveis.
- O botão principal agora é Verificar atualização. A configuração do GitHub fica em Opções avançadas, separada de Baixar e Instalar atualização.

## Como atualizar

Na janela principal: **Atualizações → Verificar agora → Baixar atualização → Instalar atualização**. O aplicativo é encerrado para abrir o instalador na mesma pasta, preservando perfis e conta.

Quem ainda usa a 0.5.1 precisa instalar esta versão manualmente uma vez; a 0.5.1 não possui o canal de atualização. Quem já instalou a 0.5.2 oficial recebe esta versão pelo painel Atualizações. O canal é SPANKATV/spankatvBOOST no GitHub Releases.

Esta é uma correção visual. Dados do jogo, Hidden Cubes, detecção de áudio, permissões da conta e cores funcionais de vida/cura permanecem como estavam.

# spankatvBOOST 0.5.2 — notas de correção

- Corrigido o nome exibido no Gerenciador de Tarefas: processo principal e subprocessos agora usam spankatvBOOST.
- O capturador de áudio passou a usar spankatvBOOST Áudio.
- Adicionado painel Atualizações e correções, com notas da versão atual.
- Preparado canal de GitHub Releases: aviso de nova versão, download com verificação SHA-256 e abertura do instalador.
- Configurações, perfis, autenticação original e histórico foram preservados.

## Migração

Quem usa a 0.5.1 precisa instalar esta versão uma vez manualmente para receber o novo canal. O canal oficial é SPANKATV/spankatvBOOST no GitHub Releases. A versão verifica esse canal na abertura e a cada seis horas; quando houver uma versão superior, o app mostra o aviso e as notas de correção.

## Correções de áudio incluídas da 0.5.1

- Reconhecimento calibrado com amostras perto/longe e ambiente sem cubo.
- Escuta contínua, prévia de 45 segundos e teste de notificação.
- Notificação sobre o jogo sem roubar foco, além dos avisos internos e do Windows.
- Hidden Cubes mantém seu minimapa separado; o restante do mapa não foi alterado.
